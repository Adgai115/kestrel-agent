## CLI Matrix

The release matrix covered:

`help`, `version`, `doctor`, `doctor --deep`, `gateway status`, `task list`, `task cancel`, `memory search`, `skill list`, `cron list`, `cron add`, `cron missed`, `queue inbox`, `queue outbox`, `queue dead`, `timeline recent`, `review list`, `session create`, `session load`, `session archive`, `session list`, `timeline session`.

`gateway start` and `gateway restart --verify` are long-running daemon commands. Their start, health, ready, status, and stop behavior was covered through Gateway E2E and direct Gateway process tests.

`review accept/reject` was not run against the real local memory queue during release CLI matrix to avoid mutating user review state; the review state machine is covered by `@kestrel/memory` tests.

## Secret Scan Notes

PowerShell full-tree scan detected a real local `KESTREL_API_KEY` in `.env`. This file is ignored by `.gitignore`, not tracked by Git, and must not enter the public export.

Tracked-file scan found only expected non-secret examples:

- Private user-test report: local test Bearer token string.
- `packages/memory/test/index.test.ts`: generic secret redaction fixture.

## Stress Test Notes

An exploratory 300 fully simultaneous connection burst on Windows produced transient `ECONNREFUSED`, consistent with local listener/backlog exhaustion. This is not a release blocker for the documented v1.1.0 boundary: local/private Gateway usage rather than internet-facing high-QPS service.

The accepted pressure gate is bounded concurrency 40 with 1001 total requests across health, status, RPC, diagnostics, queue, and confirmation create/resolve. That gate passed with zero failures.
